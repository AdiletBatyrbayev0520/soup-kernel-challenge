Every recomputed layer costs about 0.14 s of wall time and saves about 110 MiB. Score estimate
(`35·ln s / ln s_best + 30·ln m / ln m_best`, gains under 5% count as 1.0, and taking our own
best values as "best team"): 0 layers 52 points, 7 layers 40, 14 layers 23, 28 layers 30 but not
admitted. Speed is weighted higher and the memory gain per layer is small, so recompute is
**off** in every machine profile. The knob stays for a GPU where memory is the limit.

## Limits

- One run per configuration, 5090, bf16. On a T4 (fp16, compute-bound) recompute costs
  relatively more time, which only strengthens the "off" default; the attention gain should
  hold (flash runs on sm_75 in fp16 as mem-efficient / flash, the GQA path either way).
- Check 8's 10% margin on time is what rules out full recompute, not the score.
- `causal_sdpa.right_padded` does one host sync per step. TRL 0.29.1 always pads right, but the
  check keeps the patch correct for any other collator.
- The fused CE still imports Soup's private `ChunkedStep`, `STEP_ATTR` and `_log_trl_metrics`
  (`soup_cli.utils.stream_loss_chunk`). Copying those ~20 lines into `solution/` would remove
  the dependency before submission.
