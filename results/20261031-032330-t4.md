# Tesla T4 results — AWS g4dn.xlarge (single T4, 15,360 MiB), 2026-10-31

The jury's GPU. One `g4dn.xlarge` (AWS profile `freedom`, eu-central-1, Deep Learning AMI),
Python 3.12, the README's pinned packages (torch 2.15.0+cu132, triton 3.9.0, transformers 5.16.1,
peft 0.20.0, trl 0.29.1, bitsandbytes 0.50.2), fp16 compute, GPU idle at 0 MiB before each run.
Branch `unsloth` at the round-2 state (8 features). Rows: `results/t4/results.csv`,
`process_profile.csv`, `process_report.csv`; logs copied to `runs/history/*-t4-*`.
`python results/bench.py --machine t4 <label>` per batch; one run per side per batch.

## The two knobs, measured on the T4

**Layer recompute** (`recompute_layers`, our own `torch.utils.checkpoint`; every level passes
all 10 checks here, unlike the 5090 where 28 failed check 8):

| layers | wall | peak | speedup | memory | points (best = us / 1.3x·5x team / 1.5x·8x team) |
|---|---|---|---|---|---|
| **0** | 55.3 s | 6,111 MiB | 1.269 | 2.344 | **51.2 / 47.7 / 32.9** |
| 7 | 58.2 s | 5,297 MiB | 1.202 | 2.704 | 45.9 / 43.1 / 30.3 |
| 14 | 61.2 s | 4,481 MiB | 1.144 | 3.196 | 41.8 / 39.6 / 28.4 |
| 28 | 67.1 s | **2,957 MiB** | 1.046 (= tie) | **4.844** | 30.0 / 29.4 / 22.8 |

Points: `35·ln s/ln s_best + 30·ln m/ln m_best`, gains under 5% count as 1.0. Recompute off
wins in every scenario, so it stays off. 28 layers reaches Unsloth's offloaded-checkpointing
memory (about 2.3 GB reserved, 3.0 GB on nvidia-smi) and would still be admitted on a T4.

**Chunked lm_head** (`ce_chunk_rows`): 512 rows → 55.3 s / 6,111 MiB; 0 (full logits) →
53.6 s / 6,411 MiB. The second head GEMM in backward costs 1.7 s on the compute-bound T4 for
300 MiB. Points are a tie (50.2 vs 50.3), speed is the heavier criterion: the **T4 profile uses
0**, the 5090 keeps 512 (there it cost 3 ms per step and saved 680 MiB).

The base matches the README on memory and loss; it's 10 s faster here, probably the g4dn's
newer host CPU (startup is CPU-bound). The ratios are what the score uses.

## Limits

- One run per side per batch. Base wall time varied 70.0–70.3 s across five batches, solution
  times within a batch are comparable to about ±1%.
- Not Kaggle: same GPU and driver family, different host; the Kaggle notebook has not been run.
- The 3090 and 4090 profile rows remain unmeasured extrapolations.
